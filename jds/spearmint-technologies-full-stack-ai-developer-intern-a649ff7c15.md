# Full Stack AI Developer Intern — Spearmint technologies

*About the Role*

We are looking for an ambitious and forward thinking *Full Stack AI Developer Intern* who is passionate about software development, Artificial Intelligence, Generative AI, and the rapidly evolving world of AI Agents. This internship is designed for someone who wants to build real products rather than only learn through tutorials. You will work alongside our development and AI teams to build web applications, AI powered features, automation workflows, and intelligent AI agents. You will get hands-on exposure to the complete development lifecycle from building frontend interfaces and backend APIs to integrating LLMs and creating agentic workflows.

*What You Will Work On*

* *Full Stack Development:* Build, improve, and deploy web applications using modern frameworks. Develop frontend components, pages, dashboards, and interactive interfaces alongside backend APIs, database models, and third party integrations using Git and modern workflows.
* *AI & Generative AI:* Integrate LLMs and GenAI APIs (OpenAI, Anthropic, Google) into real applications. Work with prompt engineering, structured outputs, embeddings, semantic search, RAG, and multimodal capabilities while evaluating outputs for quality, speed, and cost.
* *AI Agents & Automation:* Help build AI agents that reason, use tools, and execute multi-step tasks using function calling, agent memory, and frameworks like LangGraph, LangChain, LlamaIndex, or CrewAI to power business automation.

*Required Skills*

* *Essential:* Basic knowledge of HTML, CSS, JavaScript, and programming fundamentals; familiarity with Python or JavaScript/TypeScript, APIs, JSON, Git/GitHub, and basic databases/SQL; strong interest in AI.
* *Good to Have:* React or Next.js; Node.js or Python/FastAPI; PostgreSQL, MongoDB, or Redis; experience using LLM APIs; basic knowledge of RAG, embeddings, and frameworks like LangChain or LangGraph; personal AI projects; Docker and cloud exposure; familiarity with MCP or agent architectures.

*Who We Are Looking For*

You are a strong fit if you are genuinely excited about AI and software development, build things independently rather than following tutorials, enjoy experimenting with new tech, learn frameworks quickly, and are comfortable debugging, iterating, and communicating effectively within a technical team.

*Internship Responsibilities*

Assist in developing production grade web applications, building AI powered features, researching models, testing prompts, implementing RAG and vector databases, building API integrations, debugging, writing clean code, documenting implementations, and collaborating with cross-functional teams.

*Preferred Background*

Currently pursuing or recently completed a degree/diploma in Computer Science, Software Engineering, IT, AI, Data Science, or a related field. Students with strong self taught skills and impressive projects are also encouraged to apply.
