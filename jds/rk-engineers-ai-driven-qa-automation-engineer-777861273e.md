# AI driven QA Automation Engineer — RK Engineers

Job Description: SDET – Automation EngineerRole Overview

We are looking for an *SDET – Automation Engineer* with strong experience in automation testing, framework development, and quality engineering. The candidate will build scalable automation solutions across web, mobile, API, and Salesforce applications while driving continuous testing and AI-driven quality practices.

Key Responsibilities

* Design, develop, and maintain automation frameworks and test scripts for web, mobile, API, and Salesforce applications.
* Build automated test suites using *Playwright (JavaScript/TypeScript), Appium, and WebdriverIO*.
* Develop automation strategies for functional, regression, integration, and end-to-end testing.
* Automate and validate Salesforce applications, workflows, integrations, and business processes.
* Perform API testing and automation for *REST/SOAP* services.
* Validate Salesforce data using *SOQL/SOSL* and support backend testing activities.
* Execute performance testing using *K6* and analyze application performance issues.
* Integrate automated tests into CI/CD pipelines using *Jenkins, GitHub Actions*, or similar tools.
* Troubleshoot test failures and provide quality improvement recommendations.
* Collaborate with developers, architects, product owners, and business teams across the SDLC.
* Contribute to automation framework improvements and mentor team members on QA best practices.

AI Exposure

* Experience or exposure to AI-driven testing tools and intelligent automation solutions.
* Understanding of AI use cases in test generation, defect prediction, and test maintenance.
* Interest in applying AI technologies to improve software quality engineering.

Required Skills

* *3–5 years of experience* in Automation Testing / SDET.
* Strong experience with:
* Playwright (JavaScript/TypeScript)
* Appium & WebdriverIO
* API Testing (REST/SOAP)
* Performance Testing using K6
* CI/CD tools (Jenkins, GitHub Actions)
* Strong understanding of Salesforce Platform:
* Sales Cloud, Service Cloud, Experience Cloud
* Custom objects, flows, validation rules, and business processes
* Experience with Git, Salesforce Apex testing, integration testing, and deployment validation.
* Excellent communication skills with a learning mindset and adaptability.
