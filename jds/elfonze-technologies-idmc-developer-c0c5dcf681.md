# IDMC Developer — Elfonze Technologies

Job Information
Date Opened 09/02/2026
Job Type Full time
Industry IT Services
Remote Job
Job Description

This is a remote position.

Key Responsibilities

Design, develop, configure, and maintain data integration solutions using Informatica IDMC.

Develop and manage mappings, mapping tasks, taskflows, and data integration processes.

Integrate data across cloud applications, databases, APIs, and on-premise systems.

Perform data transformation, validation, cleansing, and error handling as part of integration workflows.

Configure and manage connections, runtime environments, and Secure Agents.

Monitor scheduled jobs and integration processes and troubleshoot failures or performance issues.

Analyze source-to-target requirements and translate business requirements into technical integration solutions.

Perform unit testing, defect resolution, deployment, and production support activities.

Support migration and deployment of IDMC objects across development, test, and production environments.

Work closely with functional, technical, data, and business teams to resolve integration-related issues.

Maintain technical documentation, mapping specifications, deployment details, and operational procedures.

Follow established development, security, data governance, and change-management standards.

Required Skills & Experience

Hands-on experience with Informatica Intelligent Data Management Cloud (IDMC).

Strong experience with Cloud Data Integration (CDI) and associated IDMC components.

Experience developing mappings, transformations, tasks, and taskflows.

Good understanding of ETL/ELT concepts, data integration, and data migration.

Strong knowledge of SQL and relational databases.

Experience working with cloud and/or on-premise data sources and targets.

Knowledge of Secure Agent configuration, job monitoring, error handling, and troubleshooting.

Understanding of REST APIs, flat files, JSON/XML, and application integrations is preferred.

Experience with deployment and migration of Informatica objects across environments.

Strong analytical, troubleshooting, communication, and documentation skills.

Preferred Skills

Exposure to additional IDMC capabilities such as Application Integration, Data Quality, Mass Ingestion, or API integration.

Experience integrating with platforms such as SAP, Salesforce, Oracle, SQL Server, Snowflake, Azure, or AWS.

Understanding of cloud data architecture and data warehousing concepts.

Experience working in Agile delivery and collaborating with geographically distributed teams.

Qualifications

Bachelor’s degree in Computer Science, Information Technology, Engineering, or a related discipline.

Relevant hands-on experience in Informatica IDMC/data integration development.

Informatica certification would be an added advantage
