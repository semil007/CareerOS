# Data Engineer / AI Data Engineer — Pinnacle Montessori

*Role: Data Engineer – AI, API Integration & Application Monitoring*

_*Responsibilities:*_

* Design, develop, and maintain scalable data pipelines supporting property tax filing and tax-related applications.
* Build and integrate REST APIs to exchange data between internal applications, third-party tax systems, government/property databases, and external services.
* Develop data ingestion and transformation workflows using Python, SQL, and PySpark.
* Work with AI/ML teams to prepare, process, and validate data used for AI-driven tax analysis, automation, classification, and prediction use cases.
* Implement application logging, monitoring, and error tracking across APIs and data pipelines.
* Analyze application logs to identify failures, performance issues, API errors, and data-quality problems.
* Build dashboards and alerts using tools such as Splunk, ELK, Grafana, Azure Monitor, or CloudWatch.
* Ensure data accuracy, security, reliability, and auditability for property tax filing workflows.
* Collaborate with software engineers, AI/ML engineers, DevOps, and business teams to troubleshoot production issues.
* Optimize API performance, data processing jobs, and database queries.

_*Preferred Skills:*_

* Python, SQL, PySpark
* REST APIs, JSON, API authentication
* Azure / AWS / Databricks
* ETL/ELT and data pipelines
* Application logging and monitoring
* Splunk / ELK / Grafana / Azure Monitor
* Kafka or other messaging systems
* Databases and data warehouses
* AI/ML data preparation and integration
* Property tax or financial domain experience is a plus
