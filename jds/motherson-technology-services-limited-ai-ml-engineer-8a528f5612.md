# AI/ML Engineer — Motherson technology services limited

*Job Summary*

We are looking for an experienced AI/ML Engineer with 6–9 years of experience to join our team. The ideal candidate should have strong expertise in Python, Machine Learning/Deep Learning frameworks, and MLOps practices. You will be responsible for developing, deploying, and maintaining scalable AI/ML solutions while collaborating with Data Scientists and cross-functional teams.

*Key Responsibilities*

* Design, develop, and deploy Machine Learning and Deep Learning models.
* Build scalable model deployment solutions using REST APIs or gRPC.
* Develop and maintain data pipelines, preprocessing workflows, and feature engineering processes.
* Implement MLOps best practices, including model versioning, monitoring, and lifecycle management.
* Collaborate with Data Scientists and Software Engineers to deliver production-ready AI solutions.
* Optimize model performance for scalability and reliability.
* Work with cloud or on-premise infrastructure for model deployment.
* Containerize applications using Docker and support Kubernetes-based deployments where applicable.

Required Skills

* 6–9 years of experience in AI/ML development.
* Strong proficiency in Python.
* Hands-on experience with PyTorch, TensorFlow, or similar ML frameworks.
* Experience in deploying ML models using REST APIs or gRPC.
* Knowledge of MLOps tools and practices (MLflow, pipelines, model monitoring).
* Understanding of Machine Learning and Deep Learning concepts (training, inference, overfitting, evaluation metrics).
* Experience working with data preprocessing, feature engineering, and data pipelines.
* Familiarity with cloud platforms or on-premise environments.

Good to Have

* Experience with Docker and Kubernetes.
* Exposure to AWS, Azure, or Google Cloud Platform (GCP).
* Knowledge of CI/CD practices for ML applications.

Work Location: In person
