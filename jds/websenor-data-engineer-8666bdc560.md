# Data Engineer — WebSenor

Cloud Data Engineer – Data Modernization

*Job Title:* Cloud Data Engineer
*Job Type:* Full-time
*Work Mode:* Remote

Position Overview

We are looking for a highly skilled *Cloud Data Engineer* to join our team for a *Cloud Data Modernization* project. The ideal candidate will have strong hands-on experience with *Databricks as the primary data skill*, along with *Snowflake* and *Azure/AWS cloud technologies*.

You will be responsible for modernizing on-premises ETL workloads, developing scalable cloud data solutions, implementing data pipelines, and ensuring data quality, performance, security, and reliability.

Key Responsibilities

* Contribute to the migration of ETL workloads from on-premises platforms to *Azure Cloud, Databricks, and Snowflake*.
* Design, develop, and maintain data solutions using *Databricks, Azure Data Factory (ADF), SHIR, Logic Apps, ADLS Gen2, Blob Storage, and Snowflake*.
* Analyze and modernize existing on-premises ETL processes.
* Develop scalable data pipelines using *Apache Spark and PySpark*.
* Implement *CI/CD and DevOps practices* using GitHub Actions.
* Develop and maintain automated data reconciliation and validation processes.
* Implement *data quality, monitoring, observability, and validation* frameworks.
* Optimize data workloads for performance, scalability, and reliability.
* Develop complex SQL queries, stored procedures, views, and ETL transformations.
* Collaborate with cross-functional teams to ensure seamless data integration and data flow.
* Follow engineering best practices including code reviews, Git branching, pull requests, and documentation.
* Ensure data security and compliance with applicable industry standards.
* Work effectively in an *Agile delivery environment*.
* Leverage *AI-assisted development tools* such as GitHub Copilot, Databricks Assistant, ChatGPT, Claude, or similar tools to improve engineering productivity.
* Troubleshoot issues, identify risks, and proactively communicate critical dependencies and blockers.
