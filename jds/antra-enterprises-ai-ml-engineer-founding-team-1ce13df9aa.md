# AI/ML Engineer (Founding Team) — Antra Enterprises

*Job Title: AI/ML Engineer (Founding Team)*

*Date Posted:* August 4, 2026

*About Us*

We are building an *AI-powered Network Reliability Platform* that combines Edge Computing, Telemetry, AI, and Network Observability to help businesses automatically detect, diagnose, and explain network failures.

Unlike traditional monitoring tools, our platform uses an Edge Box deployed inside customer networks to collect telemetry, perform AI-powered Root Cause Analysis (RCA), and provide business-friendly insights through dashboards and intelligent alerts.

We're looking for a passionate AI Engineer who enjoys solving real-world infrastructure problems rather than only building chatbots.

*What You'll Build*

You'll contribute to the core AI layer of our platform, working on:

* *AI-based Root Cause Analysis (RCA)* for complex network telemetry.
* *Telemetry Data Analysis & Time-Series Anomaly Detection*.
* *Network Incident Correlation & AI-Powered Incident Summarization*.
* *Recommendation Engines & Predictive Maintenance Capabilities*.
* *AI Model Evaluation, Optimization, and LLM Integration* (where applicable).

*Responsibilities*

* Design and implement AI models tailored for network reliability and performance.
* Analyze complex telemetry, logs, metrics, and time-series datasets.
* Build robust anomaly detection and incident classification pipelines.
* Research modern AI techniques for infrastructure monitoring and digest technical research papers.
* Integrate LLMs and generative agents where they provide practical operational value.
* Work closely with backend and Edge engineers to optimize models for edge deployment.
* Write clean, maintainable, and well-documented code.

*Required Skills*

* *Programming:* Python, SQL, Git & GitHub.
* *AI / ML Fundamentals:* Deep Learning basics, Supervised & Unsupervised Learning, Feature Engineering, Model Evaluation.
* *Frameworks:* PyTorch or TensorFlow, Scikit-learn, Pandas, NumPy.
* *LLM & Generative AI:* Basic understanding of LLMs, Prompt Engineering, RAG, Embeddings, Vector Databases, Hugging Face.
* *Data Handling:* Data preprocessing, Time-series data analysis, Log & Metrics processing.

*Good to Have / Bonus Skills*

* *Advanced Frameworks & Tools:* LangChain, LangGraph, Ollama, vLLM, OpenAI/Gemini API, FastAPI, Kafka, Redis, PostgreSQL, Neo4j, GraphRAG, Time-series databases.
* *System Design:* Microservices, Cloud fundamentals.
