# Technical Project Manager — Bao Bao

*About the Role*

Bao Bao Pte Ltd is a Singapore-based technology company providing software development, AI, automation, system integration, and digital transformation solutions.

We are looking for a *Technical Project Manager with a coding / software development background* to manage technology projects from client requirement gathering through planning, development, testing, deployment, and delivery.

This is a *fully remote role*, and all client meetings, project coordination, documentation, and team management will be conducted online.

*Key Responsibilities*

*Client & Requirement Management*

* Attend online client meetings to understand business and technical requirements.
* Gather, analyse, document, and clarify functional and technical requirements.
* Translate client requirements into project scope, user stories, technical tasks, and development priorities.
* Act as the main coordination point between clients, developers, technical teams, and management.
* Provide regular project updates and manage client expectations, changes, risks, and outstanding decisions.

*Project Planning & Delivery*

* Prepare project plans, schedules, milestones, deliverables, and task dependencies.
* Coordinate projects from requirements gathering through development, testing, UAT, deployment, and handover.
* Track project progress and ensure delivery according to agreed timelines and requirements.
* Identify and manage project risks, technical blockers, dependencies, and delays.
* Maintain project documentation, meeting notes, action items, issue logs, and status reports.
* Manage multiple projects or workstreams when required.

*Team Management*

* Coordinate developers, UI/UX designers, infrastructure engineers, AI engineers, vendors, and other project resources.
* Assign and track tasks based on priorities and timelines.
* Conduct internal project meetings and follow up on outstanding actions.
* Ensure development teams clearly understand requirements, priorities, acceptance criteria, and deadlines.
* Work with technical teams to resolve blockers and delivery issues.

*Technical Coordination*

* Participate in discussions relating to system architecture, APIs, databases, integrations, and application workflows.
* Review technical requirements with developers and assess implementation feasibility.
* Understand API documentation, JSON requests/responses, authentication methods, database structures, and third-party integrations.
* Support coordination of testing, troubleshooting, defect resolution, deployment, and production handover.

*Mandatory Requirements*

* *2–5 years of relevant experience* in Technical Project Management, Software Development, Software Project Coordination, Business Analysis, Product Delivery, or a related technology role.
* Previous hands-on software development / coding experience is mandatory.
* Experience managing software development or system integration projects.
* Strong experience in client meetings, requirement gathering, project planning, and team coordination.
* Ability to translate business requirements into structured technical tasks for developers.
* Strong understanding of the Software Development Life Cycle (SDLC).
* Strong written and verbal communication skills.
* Good documentation, organisation, problem-solving, and stakeholder management skills.
* Ability to work independently and manage remote development teams.

*Technical Requirements*

Candidates should have practical experience or good working knowledge in several of the following:

* REST APIs and API integration
* JSON and web services
* SQL and relational databases
* Frontend and backend application architecture
* Git / GitHub / GitLab
* JavaScript / TypeScript
* Python
* Node.js
* React, Angular, Vue.js, or similar frameworks
* Cloud platforms such as Azure, AWS, or Google Cloud
* Authentication concepts such as OAuth, JWT, SSO, and API keys
* AI, automation, machine learning, or LLM-based applications
* CRM, ERP, or third-party system integrations

The candidate is *not expected to work as a full-time developer*, but must have sufficient coding experience and technical knowledge to communicate confidently with developers, understand technical implementation approaches, review development progress, and identify potential technical issues.

*Project Management Tools*

Experience with tools such as the following will be an advantage:

* Jira
* Microsoft Project
* Notion
* Microsoft Teams
* GitHub
* Google Workspace / Microsoft 365

Knowledge of Agile, Scrum, Kanban, Waterfall, or hybrid project management methodologies is preferred.

*Key Competencies*

* Strong client-facing communication
* Technical and analytical thinking
* Requirement gathering
* Project planning and scheduling
* Team coordination and leadership
* Problem-solving
* Strong ownership and accountability
* Ability to manage changing requirements and priorities
* Ability to work effectively with remote and multicultural teams

*Remote Working Requirements*

Candidates must have a reliable computer and internet connection and be comfortable attending frequent online meetings with clients and internal teams.

The successful candidate must be responsive during working hours and available for meetings and project coordination with the Singapore team and clients when required.

*Ideal Candidate*

We are looking for a hands-on Technical Project Manager who understands software development, not simply a project administrator.

The ideal candidate should be able to speak directly with clients, understand and challenge requirements where necessary, translate them into technical tasks, coordinate developers, manage project schedules and risks, and drive projects through to successful delivery.

A strong combination of *coding experience, technical understanding, communication skills, project management, and ownership of delivery* is essential.
