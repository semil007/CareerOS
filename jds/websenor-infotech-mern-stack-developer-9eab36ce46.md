# MERN Stack Developer — WebSenor InfoTech

Job Description

Experience: 6+ Years

Employment Type: Full-Time

Work Mode: Remote

Job Summary

We are looking for an experienced MERN Stack Developer with 6+ years of professional experience in designing, developing, and maintaining scalable web applications using MongoDB, Express.js, React.js, and Node.js.

The ideal candidate should have strong hands-on experience in full-stack development, RESTful APIs, database design, frontend development, application performance optimization, security, and modern software development practices.

The candidate will work closely with product managers, UI/UX designers, backend developers, QA engineers, and other stakeholders to deliver scalable, secure, and high-quality web applications.

Key Responsibilities

Design, develop, test, and maintain scalable web applications using the MERN stack.

Develop responsive and reusable user interfaces using React.js.

Build scalable backend services and RESTful APIs using Node.js and Express.js.

Design and optimize MongoDB databases, schemas, queries, and indexes.

Integrate frontend applications with backend APIs and third-party services.

Implement authentication, authorization, and application security.

Develop reusable components and maintain clean, modular, and maintainable code.

Optimize application performance, scalability, and response times.

Troubleshoot and resolve production issues, bugs, and performance bottlenecks.

Work with Git-based version control and participate in code reviews.

Collaborate with QA teams for testing and defect resolution.

Participate in Agile/Scrum ceremonies, sprint planning, stand-ups, and retrospectives.

Contribute to architecture and technical design discussions.

Mentor junior developers and provide technical guidance.

Maintain technical documentation where required.

Required Skills

6+ years of professional software development experience.

Strong hands-on experience with MongoDB, Express.js, React.js, and Node.js.

Strong proficiency in JavaScript and/or TypeScript.

Strong knowledge of React.js, React Hooks, component architecture, and state management.

Strong experience developing RESTful APIs using Node.js and Express.js.

Good understanding of MongoDB database design, aggregation, indexing, and optimization.

Experience with HTML5, CSS3, and responsive web development.

Experience with API integration and third-party services.

Understanding of authentication mechanisms such as JWT/OAuth.

Experience with Git/GitHub/GitLab/Bitbucket.

Strong debugging and problem-solving skills.

Good understanding of web application security and performance optimization.

Experience working in Agile/Scrum environments.

Good to Have

TypeScript experience.

Next.js experience.

Redux/Redux Toolkit or other state management frameworks.

Experience with AWS/Azure/GCP.

Docker and containerization.

CI/CD pipelines.

Microservices architecture.

Redis or caching technologies.

Unit and integration testing using Jest, Mocha, Cypress, or similar tools.

Experience mentoring development teams.

Qualifications

Bachelor's degree in Computer Science, Information Technology, Software Engineering, or a related field.

6+ years of relevant development experience.

Strong communication and interpersonal skills.

Ability to work independently and collaboratively.

Strong ownership and analytical skills.
